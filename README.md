# Campus Tree

[大学基本情報 2025（R7）](https://portal.niad.ac.jp/ptrt/r07.html) に基づく国公立大学の修士課程・博士課程の学生の統計、および各大学院・研究科に在籍する LabBase ユーザーの可視化ツール。

## 起動

```sh
npm install
npm run build
uv run tree
```

ブラウザで <http://127.0.0.1:8000> を開く。

### 開発者向け

```sh
npm run dev
```

ブラウザで <http://127.0.0.1:5173> を開く。UI 変更等が即時反映される。
