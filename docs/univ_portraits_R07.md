# 大学ポートレート（令和 7 年度版）データ概要

大学ポートレートが公開している [大学基本情報 2025（R7）](https://portal.niad.ac.jp/ptrt/r07.html) の概要を示す。人数は原則として男女別に収録されている。

## 大学全体

| CSV | 内容 |
| --- | --- |
| `2025_07go_1.csv` | 大学ごとの大学院担当者、休職者、外国人教員を、職位別に集計したデータ。職位は学長、副学長、教授、准教授、講師、助教、助手に分かれる。 |
| `2025_07go_A.csv` | 大学ごとの学生数を、昼夜、博士・修士・専門職学位課程、学部本科、専攻科、別科、科目等履修生などの区分別に集計したデータ。 |
| `2025_07go_B.csv` | 大学の学部・組織ごとの本務教員数を、職位別に集計したデータ。学長・副学長、学部、大学院、附属病院、附置研究所などを含む。 |
| `2025_07go_C.csv` | 大学ごとの本務・兼務職員数を、事務系、技術技能系、医療系、教務系、その他に分けたデータ。学生の健康管理や附属病院に所属する看護師数も含む。 |
| `2025_07go_Z.csv` | 大学ごとの兼務教員数を、学長、副学長、教員からの兼務、教員以外からの兼務に分けたデータ。外国人兼務教員数の再掲を含む。 |

## 大学学部

| CSV | 内容 |
| --- | --- |
| `2025_08go_2.csv` | 大学・学部ごとの休学者数を、昼夜、課程、学年、性別に分けたデータ。 |
| `2025_08go_3.csv` | 大学・学部ごとの最低在学年限を超過した学生数を、入学年度相当と性別に分けたデータ。編入学者は対象外。 |
| `2025_08go_7.csv` | 大学・学部ごとの専攻科、別科、科目等履修生・聴講生・研究生の学生数を集計したデータ。 |
| `2025_08go_D.csv` | 大学の学科ごとの在籍学生数、入学志願者数、入学者数を、学年と性別に分けたデータ。 |
| `2025_08go_G.csv` | 大学・学部への入学者数を、出身高校の都道府県と性別に分けたデータ。 |
| `2025_08go_O.csv` | 大学・学部への入学者数を、年齢と性別に分けたデータ。外国の学校卒、専修学校高等課程卒、高卒認定等、留学生の再掲を含む。 |
| `2025_08go_R.csv` | 短期大学、高等専門学校、専修学校、高等学校等の専攻科から大学へ編入した学生数を、編入元、年次、性別に分けたデータ。 |

## 大学院

| CSV | 内容 |
| --- | --- |
| `2025_09go_4.csv` | 大学・研究科ごとの休学者数を、昼夜、課程、学年、性別に分けたデータ。 |
| `2025_09go_5.csv` | 大学・研究科ごとの最低在学年限を超過した学生数を、入学年度相当と性別に分けたデータ。編入学者は対象外。 |

| `2025_09go_H.csv` | 大学院の専攻ごとの在籍学生数を、学年と性別に分けたデータ。社会人学生数の再掲を含む。 |
| `2025_09go_I.csv` | 大学院の専攻ごとの入学志願者数と入学者数を、出身大学区分と性別に分けたデータ。出身区分は当該大学、国立、公立、私立、外国、その他。 |
| `2025_09go_S.csv` | 大学・研究科への入学者数を、年齢と性別に分けたデータ。社会人と留学生の再掲を含む。 |

## 外国人学生

| CSV | 内容 |
| --- | --- |
| `2025_11go_bekkei.csv` | 専攻科・別科および科目等履修生・聴講生・研究生に該当する外国人学生数を、学校、留学種別、専攻分野、性別に分けた別掲データ。 |
| `2025_11go_gkssu.csv` | 外国人学生数を、学校、学校種別、国籍・地域、国費・私費などの留学種別、専攻分野、性別に分けたデータ。専攻科・別科および科目等履修生等の再掲を含む。 |

## 土地・建物

| CSV | 内容 |
| --- | --- |
| `2025_20go.csv` | 学校ごとの土地と建物の面積を、用途、構造、所有・借用別に集計したデータ。建物の増減、前年度面積、職員住宅・看護師宿舎の土地と建物も含む。単位は平方メートル。 |

## 卒業者と就職

| CSV | 内容 |
| --- | --- |
| `2025_30go_2_1.csv` | 学科・専攻ごとの卒業者数を、進学、就職、臨床研修、その他などの卒業後状況と性別に分けたデータ。博士課程の満期退学者・ポストドクター、入学年度別卒業者数も含む。 |
| `2025_30go_2_1_bekkei.csv` | 学部・研究科などの卒業者数を、年齢、性別、学校・課程区分に分けた別掲データ。 |
| `2025_30go_2_2.csv` | 学科・専攻ごとの就職者数を、詳細な職業分類と産業分類、性別に分けたデータ。 |
